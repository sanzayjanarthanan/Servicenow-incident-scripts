## File Contents
- `*.xml` — The exported ServiceNow Local Update Set containing the project deliverables (Client Scripts, UI Policies, Business Rules, etc.).

---

## How to Import & Preview in ServiceNow

To view or test the contents of this Update Set on another ServiceNow Personal Developer Instance (PDI):

1. **Log in** to your ServiceNow instance as an System Administrator (`admin`).
2. Navigate to **System Update Sets** > **Retrieved Update Sets**.
3. Under **Related Links**, click **Import Update Set from XML**.
4. Choose the `.xml` file from this repository and click **Upload**.
5. Open the uploaded Retrieved Update Set record.
6. Click **Preview Update Set**.
7. Once the preview finishes with no errors, click **Commit Update Set**.
